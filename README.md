# Financial Ledger Reconciliation Tool

A robust Python-based application designed to automate the reconciliation process between two financial ledgers. This tool identifies matches, discrepancies, and anomalies using Pandas for data manipulation and Flask for a seamless web-based user experience.

## 🚀 Live Demo
https://reconciliation-project-zkn2.onrender.com

## ✨ Features
* **Automated Matching:** Compares internal ledgers against bank statements based on Transaction ID, Date, and Amount.
* **Anomaly Detection:** Flags duplicate entries and significant discrepancies in totals.
* **File Support:** Supports `.csv` and `.xlsx` file uploads.
* **Interactive Dashboard:** A Flask-powered UI to view reconciliation summaries and download "Difference Reports."
* **Data Cleaning:** Built-in preprocessing to handle missing values and formatting inconsistencies.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Analysis:** Pandas, NumPy
* **Web Framework:** Flask
* **Frontend:** HTML5, CSS3 (Bootstrap)
